# Projects

## Framework-FreeFE

Framework-FreeFE is a framework-free portfolio frontend built with
standard HTML, CSS, and JavaScript.

The project uses FastAPI for backend services and includes an AI assistant.

## Portfolio AI/RAG

The portfolio includes a Retrieval-Augmented Generation system that
retrieves relevant portfolio information before generating an AI response.

The RAG architecture is designed to keep portfolio knowledge separate
from the application logic and AI service.

## Agentic Systems

The portfolio explores agentic systems, LLM applications, AI APIs,
prompt engineering, and practical automation.
