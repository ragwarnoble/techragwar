# Ragwar Tech

Ragwar Tech is a software engineering portfolio focused on modern web
development, backend systems, artificial intelligence, LLM applications,
APIs, deployment, and agentic systems.

## Technologies

- Python
- FastAPI
- JavaScript
- HTML
- CSS
- OpenAI APIs
- REST APIs
- SQL
- Docker
- Git
- GitHub
- CI/CD

## Framework-FreeFE

Framework-FreeFE is a framework-free frontend project.

The frontend is built using standard HTML, CSS, and JavaScript without
React, Vue, Angular, or another frontend framework.

The project uses FastAPI for backend services and includes an AI assistant.

## AI Projects

The portfolio includes work involving:

- LLM applications
- Retrieval-Augmented Generation
- AI assistants
- Agentic systems
- Prompt engineering
- AI APIs

## Engineering Focus

The goal is to build practical, maintainable, portable software systems
with clear separation between frontend, backend, AI services, and data.
