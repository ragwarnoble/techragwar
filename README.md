# Framework-FreeFE

A modern portfolio frontend built without a frontend framework.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Web APIs
- Responsive Design

## Features

- Responsive portfolio
- Project filtering
- Dynamic project pages
- Dark/light theme
- Scroll animations
- Contact form
- AI/LLM project showcase
